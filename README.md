# EMF Accounting & Business Advisory website

This is a responsive, single-page website with no external libraries or build step. Open `index.html` in a browser to view it.

## Contact form

The enquiry form opens a visitor's default email app and prepares a message for `info.financeprof@gmail.com`. It does not collect or send enquiries through a website server. Visitors need an email app configured on their device.

The service descriptions and fees are indicative and should be confirmed with EMF before engagement. Statutory audits and other regulated sign-offs are reserved for appropriately authorized professionals.
